# xAPI
Библиотека для разработки плагинов Minecraft.

## Подключение через JitPack

Добавьте репозиторий JitPack в ваш `pom.xml`:

```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>
```

Затем добавьте зависимость:

```xml
<dependencies>
    <dependency>
        <groupId>com.github.v23709789-sketch</groupId>
        <artifactId>xAPI</artifactId>
        <version>main-SNAPSHOT</version>
        <scope>provided</scope>
    </dependency>
</dependencies>
```
